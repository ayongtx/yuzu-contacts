# 柚柚通讯录（ContactsPro）

一款 iOS 本地通讯录应用：苹果通讯录的核心体验 + 五个实用创意功能。
数据全部存本机，不联网、不注册、不上传任何服务器。

| 项目 | 说明 |
|---|---|
| 最低系统 | iOS 17 |
| 数据框架 | SwiftData（本地存储） |
| 界面 | SwiftUI 原生 |
| 交付物 | 未签名 IPA → 用爱思助手自签安装 |
| 仓库 | https://github.com/ayongtx/yuzu-contacts |

## 功能清单

### 基础（对齐苹果通讯录）
- 联系人列表：A-Z 拼音分组 + 右侧索引条（支持按住滑动快速定位）
- 搜索：姓名 / 公司 / 号码 / 拼音全拼 / 拼音首字母（如输 `zs` 找到张三）
- 联系人详情：多号码（可设主号）、邮箱、地址、纪念日、备注、标签
- 新建 / 编辑 / 删除；一键拨号、短信、邮件
- 常用联系人置顶；滑动标星、滑动删除
- 文字头像自动生成（按名字哈希配色，稳定不闪变）
- 6 套主题色可切换

### 创意功能

**1. T9 九宫格检索**
数字键直接找联系人：`94264`→张、`726`→三、`97`→张三首字母；输号码 `138` 也能按号码命中；没匹配到时可直接拨打输入的号码。

**2. 隐私保险箱**
把指定联系人锁起来：主列表、搜索、九宫格、雷达里全都看不见。支持面容 ID / 触控 ID，附 4 位 PIN 兜底（自签证书偶尔拿不到生物识别权限时仍可进入），退出 App 自动上锁。

**3. 雷达**
近期 60 天生日倒计时 + 自动生成四种风格的祝福文案（可复制 / 直接发短信）；超过设定天数没联系的人会提醒，点一下就能拨打。

**4. 通讯录体检 + 智能去重**
给通讯录打健康分，自动揪出：重复联系人（同名 / 同号码，一键合并）、没有号码的、没有姓名的、号码位数可疑的、信息太单薄的。

**5. 名片二维码 + 备份互通**
把自己的名片做成二维码，对方相机一扫即存；导出 / 导入标准 vCard（.vcf），可和系统通讯录、Outlook、Google 通讯录互通。

## 怎么用爱思助手自签安装

1. 电脑装[爱思助手](https://www.i4.cn/)，iPhone 用数据线连上电脑
2. 爱思助手顶部 → **工具箱** → **IPA 自签**（有的版本叫「IPA 签名」）
3. 选「**使用 Apple ID 签名**」：
   - Apple ID：普通 Apple ID 邮箱即可（不用开发者账号）
   - 密码：⚠️ 需要 **App 专用密码**，不是登录密码。去 [appleid.apple.com](https://appleid.apple.com) → 登录和安全 → App 专用密码 → 生成一个粘贴进来
4. 选择 `ContactsPro-unsigned.ipa`
5. 点**开始签名**，完成后点**安装**
6. 手机首次打开会提示「不受信任的开发者」：
   **设置 → 通用 → VPN 与设备管理** → 找到你的 Apple ID → **信任**
7. 打开 App

### 免费个人签名的限制
| 规则 | 说明 |
|---|---|
| 证书 7 天有效 | 7 天后打不开，重连爱思助手签一次即可。**数据不会丢**（存在 App 沙盒里） |
| 最多 3 个自签 App | 免费 Apple ID 同时只能签 3 个不同的 App |
| 建议固定 Apple ID | 每次用同一个 ID 签名，Bundle ID 保持 `com.cenglou.contactspro` |

## 常见问题

**编译失败？**
- 进 Actions 看红色 ✗，展开失败的步骤看 `error:` 行。目前已知的坑都修过了。

**安装后闪退？**
- 需要 iOS 17 及以上。到 设置→通用→关于本机 确认版本号。

**Face ID 不可用？**
- 正常现象，自签证书有时拿不到该权限。App 内置 PIN 兜底：保险箱 → 设置 4 位 PIN。

**想把数据搬到新手机？**
- 更多 → 导出备份（.vcf）→ 新手机装好本 App → 更多 → 从 .vcf 文件导入。

**想改 App 显示名？**
- 改 `project.yml` 里的 `CFBundleDisplayName`（当前「柚柚通讯录」），推送后自动重新编译。
